Phone screenshots for F-Droid / Fastlane.

Captures are the running QRaft FOSS PWA (same editor, profiles, wallpaper,
and settings as the Android app) at a Pixel-sized viewport. This environment
has no Android emulator; regenerate with:

```bash
bash scripts/capture-fdroid-screenshots.sh
```

Dummy, placeholder, sample, or tiny (≤8px) PNGs fail `scripts/check-fdroid-screenshots.sh`.
