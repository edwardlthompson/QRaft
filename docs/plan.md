# Product plan

Milestones for QRaft after Sprint 0 bootstrap.

1. **Core encode + square render** — Nayuki → matrix → square bitmap + unit tests ✅ (this kickoff)
2. **Custom Canvas renderer** — module shapes, finder styling, center logo, scannability warnings
3. **Profile save/load** — DataStore (+ optional Room), tags, search
4. **Glance widget** — cached bitmap, tap-to-brighten fullscreen, caption
5. **Wallpaper engine** — DisplayMetrics, safe-zone, set-wallpaper, PNG export
6. **Polish** — carousel, blur/lock, SVG/JSON export, a11y, F-Droid metadata

See `BUILD_PLAN.md` for labeled AGENT/HUMAN/ADB/AUTO rows.
