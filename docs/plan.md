# Product plan

Milestones for QRaft after Sprint 0 bootstrap.

1. **Core encode + square render** — Nayuki → matrix → square bitmap + unit tests ✅
2. **Custom Canvas renderer** — diamond/pill/blob + finder pupil + eye color + logo cut-out ✅ Sprint 5
3. **Profile save/load** — DataStore seed, editor save/load/delete, history, clipboard backup ✅ Sprint 6
4. **Glance widget** — live QR image, BrightenActivity, config, TalkBack, carousel Next ✅ Sprint 7
5. **Wallpaper engine** — DisplayMetrics overlay, set home/lock/both, SAF PNG ✅ Sprint 8
6. **Polish** — PNG/PDF/SVG/JSON, style-JSON QR, packs, Fastlane slots ✅ Sprint 9

North-star: URL + style on Home (pinned preview) → save profile → lock-screen widget → wallpaper → export.

See `BUILD_PLAN.md` (Sprint 5–9 AGENT archived) and `docs/COMPETITOR_GAPS.md`.
